# Contributing

Thanks for helping improve OpenSource Pulse.

1. Open an issue for a substantial change before starting work.
2. Fork the repository and create a focused branch.
3. Keep changes dependency-free unless there is a clear reason otherwise.
4. Add or update tests for behavior changes.
5. Run `npm test` before opening a pull request.
6. Explain what changed, why it matters, and how it was tested.

Please keep reports reproducible and avoid including secrets or private repository data.
